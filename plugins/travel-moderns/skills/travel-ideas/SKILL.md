name: travel-ideas
description: Find, save, update, archive, or restore places the user wants to visit and rough future trip ideas in Xingjian Travel. Use for clear travel wishes or questions about saved ideas.
---

Search the family idea library using `travel_list_ideas` before saving. Use `travel_save_idea` for genuine user intent, with a chat source. Update an existing idea with its ID and version. Leave dates, budgets, and travelers unspecified where absent. Disregard incidental mentions, negative intent, and assistant suggestions.

Keep ideas separate from formal trips and bookings. Verify the saved record in the tool receipt. If a write outcome is unknown, check the existing record before retrying with the same request ID.
