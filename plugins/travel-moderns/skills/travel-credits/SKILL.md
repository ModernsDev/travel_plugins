---
name: travel-credits
description: Find, record, or correct supplier-issued travel credits in Xingjian Travel. Use for credit balances, holders, currencies, restrictions, and travel-by or book-by deadlines.
---

Search with `travel_list_credits` and deduplicate by holder, supplier, and documented source. Use `travel_save_credit` to record evidenced facts. Include the original amount, remaining balance, currency, holder, restrictions, and deadline type where known. A travel-by deadline is distinct from a book-by deadline. Keep unverified imports and expected settlements separate from available balances.

Use the current ID and version for updates. Verify the saved record in the tool receipt. If a write outcome is unknown, check the existing record before retrying with the same request ID. Using or transferring credit requires a separate authorized supplier capability.
